# Gym Management System

Sistema administrativo para academias e pequenos centros de treinamento.

## Objetivo

Digitalizar o controle manual de alunos, mensalidades e informações administrativas.

## Tecnologias

- Java
- Spring Boot
- Spring Data JPA
- Maven

## Funcionalidades atuais

- Entidade Student
- Repository
- Service layer
- CRUD inicial em desenvolvimento

## Próximos passos

- Controller REST
- Busca por nome
- Controle de mensalidades
- Relatórios financeiros
